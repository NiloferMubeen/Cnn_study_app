Pooling

Discover how CNNs shrink feature maps to cut computation, build position tolerance, and focus on what matters — through an interactive step-by-step pooling demo.

01

What is Pooling?

After a convolution layer produces a feature map, a pooling layer slides a small window across it and summarises each region into a single number — either the maximum or the average of the values inside. The result is a smaller feature map with the same number of channels.

Pooling does two important jobs: it reduces spatial size (fewer numbers to process in the next layer) and it gives the network translation invariance — the ability to recognise the same feature even if it shifts a few pixels.

💡 Analogy

Imagine summarising a photograph by dividing it into a grid of 4-pixel squares and writing down only the brightest colour in each square. You lose exact pixel positions, but keep the essential information — and the picture is four times smaller.

WHY AFTER CONVOLUTION?

Convolution maps are big and redundant — nearby values are highly correlated. Pooling compresses them aggressively while preserving detected features, so the next conv layer covers a wider area of the original image for free.

TYPICAL SETTINGS

The most common choice is a 2×2 window with stride 2. This halves both height and width, reducing the feature map to one quarter its size. No learnable parameters — pooling is entirely parameter-free.

Output Size & Translation Invariance

Pooling shrinks the spatial dimensions according to the same formula as convolution. With a 2×2 window and stride 2 (the most common setup), a 6×6 feature map becomes a 3×3 map — four times fewer values, but all the key information preserved.

Translation invariance means the network produces the same (or very similar) output even if the input pattern shifts by a pixel or two. Max pooling achieves this because the max value in a 2×2 region stays the same whether the activating feature is at the top-left or bottom-right of that region.

📐 Output Size Formula
General ⌊(N − F) / S⌋ + 1
2×2, stride 2 ⌊(N − 2) / 2⌋ + 1 = N / 2
N = input size  ·  F = pool window  ·  S = stride  ·  No learnable parameters

Global Average Pooling (GAP) takes this to the extreme — instead of a sliding window, the entire feature map (however large) is averaged into a single number per channel. A network with 128 channels before GAP produces a 128-element vector ready for classification — no need for any flattening or dense layers.
