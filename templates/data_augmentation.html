Why it matters — visually

Data augmentation applies random label-preserving transforms to training images every epoch. The model never memorises pixels — it learns the concept. The gain is real and free: zero new parameters, just smarter data.

WHEN IS IT APPLIED?

Only during training — never at validation or inference. Applied on-the-fly each epoch in the DataLoader, so storage requirements don't grow.

HOW MUCH IS ENOUGH?

Start conservative. Aggressive augmentation on tasks where orientation/colour is diagnostic (e.g. pathology slides) can hurt. Measure val accuracy as you increase magnitude.

Code & When to Use

import torchvision.transforms as T

train_tfm = T.Compose([
    T.RandomCrop(32, padding=4),          # pad then crop
    T.RandomHorizontalFlip(p=0.5),         # 50% chance
    T.ColorJitter(brightness=0.3,
                   contrast=0.3, saturation=0.3, hue=0.05),
    T.RandomRotation(15),
    T.GaussianBlur(kernel_size=3, sigma=(0.1,1.5)),
    T.ToTensor(),
    T.Normalize(mean=[.5,.5,.5], std=[.5,.5,.5]),
    T.RandomErasing(p=0.5, scale=(0.02,0.33)),
])

# RandAugment — drop-in replacement
rand_tfm = T.Compose([
    T.RandAugment(num_ops=2, magnitude=9),
    T.ToTensor(),
    T.Normalize(mean=[.5,.5,.5], std=[.5,.5,.5]),
])

# MixUp — in the training loop
def mixup_batch(x, y, alpha=0.2):
    lam = np.random.beta(alpha, alpha)
    idx = torch.randperm(x.size(0))
    x_mix = lam * x + (1 - lam) * x[idx]
    return x_mix, y, y[idx], lam

# Val/test — no augmentation
val_tfm = T.Compose([T.ToTensor(),
    T.Normalize(mean=[.5,.5,.5], std=[.5,.5,.5])])
import tensorflow as tf
from tensorflow.keras import layers

aug_layer = tf.keras.Sequential([
    layers.RandomFlip("horizontal"),
    layers.RandomCrop(32, 32),
    layers.RandomTranslation(0.1, 0.1),
    layers.RandomRotation(0.08),
    layers.RandomBrightness(0.3),
    layers.RandomContrast(0.3),
], name="augmentation")

# MixUp with tf.data
def mixup(ds_one, ds_two, alpha=0.2):
    for (x1,y1),(x2,y2) in zip(ds_one, ds_two):
        lam = tf.random.uniform(())
        x_mix = lam*x1 + (1-lam)*x2
        y_mix = lam*y1 + (1-lam)*y2
        yield x_mix, y_mix

Key Terms
Augmentation
Random label-preserving transforms applied each training epoch
MixUp
x̃ = λxᵢ + (1−λ)xⱼ — blends two images and their labels
RandomErasing
Randomly zeros a rectangular patch to prevent feature over-reliance
RandAugment
Auto-samples N transforms at magnitude M — no manual tuning
TTA
Test-Time Augmentation — average N augmented predictions at inference
