Activation Functions

Without non-linearity, a hundred layers is still just one. Explore every major activation curve — ReLU, GELU, Swish, Sigmoid — plot them live and learn exactly when to reach for each one.

01

Why Non-linearity?

Every convolution and pooling layer performs linear operations — weighted sums. Stack ten such layers with no activation functions and the entire network collapses to a single equivalent linear transformation. It could never learn curves, corners, or complex patterns.

An activation function is a non-linear function applied element-wise to every value in a feature map after a convolution. It lets the network model complex relationships — making deep networks vastly more powerful than any shallow linear model.

💡 Analogy

A linear layer is a dimmer switch — it can brighten or dim, but only proportionally. An activation function is the decision gate — it chooses to fire or stay silent, enabling the network to make decisions, not just scale values.

WHERE THEY LIVE

Activations sit immediately after every conv or linear layer: Conv → BatchNorm → Activation → Pool. Applied to every element in the feature map independently, millions of times per forward pass.

KEY PROPERTIES NEEDED

A good activation must be non-linear, differentiable (for backprop), fast to compute (applied everywhere), and avoid vanishing gradients — the main killer of deep networks.

02

The Functions — Click to Explore

Click any card to load that function into the live plotter below. Each function handles positive and negative inputs differently — that difference is what shapes how a network learns.

ReLU
Most used
f(x) = max(0, x)

Zero for negatives, identity for positives. Extremely fast. Default for hidden layers in most CNNs today.

Leaky ReLU
Fixes dying
f(x) = max(0.01x, x)

Small slope (0.01) for negatives prevents neurons from permanently dying. Simple swap-in for ReLU.

Sigmoid
Output layers
f(x) = 1 / (1 + e⁻ˣ)

Squashes all values into (0, 1). Only for binary outputs — saturates and kills gradients in hidden layers.

Tanh
Zero-centred
f(x) = (eˣ − e⁻ˣ) / (eˣ + e⁻ˣ)

Like sigmoid but outputs (−1, 1). Zero-centred — slightly better gradients. Used in RNNs and LSTMs.

GELU
Transformers
f(x) ≈ x · σ(1.702x)

Smooth probabilistic ReLU used in BERT, GPT, and Vision Transformers. Slightly outperforms ReLU on many tasks.

Swish
EfficientNet
f(x) = x · σ(x)

Self-gated, found by neural architecture search. Slightly negative for small negatives — outperforms ReLU on very deep nets.

⚰️ The Dead Neuron Problem (ReLU only)
If a neuron's pre-activation value is always negative, ReLU always outputs 0 and the gradient is also 0. No signal flows back. The neuron is permanently "dead" — it never updates. With high learning rates, up to 40% of neurons can die. Leaky ReLU, GELU, and Swish all solve this.

PRACTICAL STARTING POINT

Start with ReLU. If you observe dead neurons (weights collapsing to zero), switch to Leaky ReLU. For transformer-based vision models use GELU. For EfficientNet-style architectures, try Swish.

BATCHNORM + ACTIVATION

BatchNorm (applied before activation) normalises inputs so they land near zero — right in the most sensitive region of ReLU and away from saturation zones for sigmoid/tanh. The two work together closely.
