PyTorch vs TensorFlow — Side by Side

PyTorch and TensorFlow are the two dominant deep learning frameworks. PyTorch uses a dynamic computation graph — great for research and debugging. TensorFlow 2 (with Keras) uses eager execution by default, making it equally accessible while offering production-grade tooling (TFLite, TF Serving, TF.js).

Both can build identical CNN architectures. The concepts you've learned — convolution, pooling, activations, BatchNorm — map 1-to-1 between them. Choose PyTorch for research flexibility; TensorFlow/Keras for production deployment pipelines.

🔥 PYTORCH STRENGTHS

Dynamic graphs for easy debugging, Pythonic feel, dominates academic research (90%+ of CVPR/ICCV papers), excellent ecosystem: torchvision, timm, Lightning, Detectron2.

🟡 TENSORFLOW STRENGTHS

Rock-solid production serving (TF Serving), mobile deployment (TFLite), browser inference (TF.js), Keras high-level API, TPU support, and Google Cloud native integration.

Full Code Reference

Complete, copy-ready implementations. Both build a 3-block CNN trained on CIFAR-10 (32×32 colour images, 10 classes).

🔥 PyTorch — Full CNN (CIFAR-10)
import torch, torch.nn as nn
import torchvision, torchvision.transforms as T

# ── Model ─────────────────────────────
class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3,32,3,padding=1),
            nn.BatchNorm2d(32), nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(32,64,3,padding=1),
            nn.BatchNorm2d(64), nn.ReLU(),
            nn.MaxPool2d(2),
            nn.Conv2d(64,128,3,padding=1),
            nn.BatchNorm2d(128), nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(128,256),
            nn.ReLU(), nn.Dropout(0.4),
            nn.Linear(256,10),
        )
    def forward(self, x):
        return self.classifier(self.features(x))

# ── Train ────────────────────────────
device = 'cuda' if torch.cuda.is_available() else 'cpu'
model  = CNN().to(device)
opt    = torch.optim.Adam(model.parameters(), lr=1e-3)
loss_fn= nn.CrossEntropyLoss()

for epoch in range(20):
    model.train()
    for x, y in train_loader:
        x, y = x.to(device), y.to(device)
        loss = loss_fn(model(x), y)
        opt.zero_grad(); loss.backward(); opt.step()

torch.save(model.state_dict(), 'cnn.pth')
🟡 TensorFlow / Keras — Full CNN (CIFAR-10)
import tensorflow as tf
from tensorflow.keras import layers, Model

# ── Model ─────────────────────────────
def build_cnn():
    inp = layers.Input((32,32,3))
    x = layers.Conv2D(32,3,padding='same')(inp)
    x = layers.BatchNormalization()(x)
    x = layers.ReLU()(x)
    x = layers.MaxPooling2D()(x)
    x = layers.Conv2D(64,3,padding='same')(x)
    x = layers.BatchNormalization()(x)
    x = layers.ReLU()(x)
    x = layers.MaxPooling2D()(x)
    x = layers.Conv2D(128,3,padding='same')(x)
    x = layers.BatchNormalization()(x)
    x = layers.ReLU()(x)
    x = layers.GlobalAveragePooling2D()(x)
    x = layers.Dense(256, activation='relu')(x)
    x = layers.Dropout(0.4)(x)
    out = layers.Dense(10, activation='softmax')(x)
    return Model(inp, out)

model = build_cnn()
model.compile(
    optimizer='adam',
    loss='sparse_categorical_crossentropy',
    metrics=['accuracy']
)

# ── Train ─────────────────────────────

Transfer Learning

Transfer learning is the most practical technique in modern deep learning. Instead of training from scratch on your small dataset, you load a model pretrained on ImageNet (millions of images, 1000 classes) and swap in a new classifier head for your task.

The pretrained backbone has already learned to detect edges, textures, shapes, and object parts. You freeze these layers (no gradient update) and only fine-tune the new head. This works with as few as a few hundred training images.

🔥 Transfer Learning — PyTorch
from torchvision.models import resnet50, ResNet50_Weights

model = resnet50(weights=ResNet50_Weights.DEFAULT)

# Freeze all layers
for p in model.parameters():
    p.requires_grad = False

# Replace final layer (1000 → N classes)
model.fc = nn.Linear(2048, num_classes)

# Only the head trains
opt = torch.optim.Adam(
    model.fc.parameters(), lr=1e-3)
🟡 Transfer Learning — TensorFlow
from tensorflow.keras.applications import ResNet50

base = ResNet50(
    weights='imagenet',
    include_top=False,
    input_shape=(224,224,3))
base.trainable = False  # freeze

x = layers.GlobalAveragePooling2D()(base.output)
x = layers.Dense(256, activation='relu')(x)
out= layers.Dense(num_classes,
         activation='softmax')(x)

model = Model(base.input, out)
model.compile(optimizer='adam',
    loss='sparse_categorical_crossentropy')
FINE-TUNING STRATEGY

Phase 1: Freeze entire backbone, train head for 5–10 epochs. Phase 2: Unfreeze last 1–2 blocks with a very low LR (1e-5). This avoids destroying pretrained weights while letting the backbone adapt to your domain.

POPULAR BACKBONES

ResNet-50 — general purpose, well-understood. EfficientNet-B0/B4 — best accuracy/param ratio. ViT-B/16 — vision transformer, best on large datasets. MobileNetV3 — edge deployment.

Saving & Inference

🔥 Inference — PyTorch
# Load saved model
model = CNN()
model.load_state_dict(
    torch.load('cnn.pth', map_location='cpu'))
model.eval()  # disables Dropout/BN training mode

transform = T.Compose([
    T.Resize((32,32)),
    T.ToTensor(),
    T.Normalize(mean=[.5,.5,.5],
                 std=[.5,.5,.5]),
])

with torch.no_grad():  # no gradient needed
    img  = transform(pil_img).unsqueeze(0)
    logits= model(img)
    pred  = logits.argmax(dim=1).item()
    prob  = logits.softmax(dim=1).max().item()
print(f"Class {pred}, Confidence {prob:.2%}")
🟡 Inference — TensorFlow
import numpy as np
from PIL import Image

# Load saved model
model = tf.keras.models.load_model('cnn.keras')

# Preprocess
img = Image.open('photo.jpg').resize((32,32))
arr = np.array(img) / 255.0
arr = np.expand_dims(arr, 0)  # batch dim

# Predict (no need for no_grad in TF)
probs = model.predict(arr, verbose=0)
pred  = np.argmax(probs)
conf  = probs[0, pred]

print(f"Class {pred}, Confidence {conf:.2%}")

# Export to TFLite (mobile)
converter = tf.lite.TFLiteConverter.from_keras_model(model)
tflite_model = converter.convert()
open('cnn.tflite','wb').write(tflite_model)
